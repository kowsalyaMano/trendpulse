# TrendPulse: What's Actually Trending Right Now

Mini project that turns daily YouTube trending-video snapshots into an evidence-backed content-strategy briefing.

## Dataset
**Trending YouTube Video Statistics** (public dataset; also available on Kaggle).  
Not claimed as original work. Country CSVs plus a `categories.csv` lookup are stored inside each Part's `data/` folder.

## Parts
| Part | Folder | Focus |
|------|--------|--------|
| 1 | [part1_python_foundations](part1_python_foundations/) | Core Python, cleaning, data structures, rule-based labels |
| 2 | [part2_numpy_pandas](part2_numpy_pandas/) | NumPy + Pandas wrangling |
| 3 | [part3_visualization_eda](part3_visualization_eda/) | Visualization, EDA & content-strategy briefing |
| 4 | [part4_sql_spreadsheet](part4_sql_spreadsheet/) | SQL + spreadsheet briefing workbook |

Each Part folder is self-contained (its own README, dependencies, notebook/code, and data).

## How to start
Open a Part folder, read its `README.md`, install that folder's requirements, then run the notebook top to bottom (**Restart and run all**).
